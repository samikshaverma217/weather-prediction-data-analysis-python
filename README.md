# Weather Prediction and Data Analysis using Python

A machine learning based web application to analyse past weather data and predict future temperature using Python, Streamlit and Scikit-Learn.

## Features
- Password Protected Dashboard
- Temperature Trend Line Chart
- Rainfall Bar Chart
- Temperature vs Humidity Scatter Chart
- Top 5 Hottest and Rainiest Days
- Search Weather by Date
- ML Prediction using Linear Regression
- Download Analysis as CSV

## Tech Stack
- Language: Python
- Dashboard: Streamlit
- Data Analysis: Pandas, NumPy
- Machine Learning: Scikit-Learn (Linear Regression)

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
